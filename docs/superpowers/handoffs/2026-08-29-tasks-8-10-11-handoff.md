### 3.2 MAJOR — persona parser reads `groups:`, not `tools:` (config + plan)
Bob 2.0.3 `parseAgentFile` uses `a.groups` and defaults to `["read","edit","execute"]`; `tools:` is ignored, so the
three "read-only" personas currently get write + execute tools (only the rx hook would stop them).
- In each `.bob/agents/*.md` frontmatter add, after the `tools:` list:
  ```yaml
  groups:
    - read
  ```
  (keep `tools: [read]` — it is the documented form; the parser ignores unknown keys).
- Same change in the three plan Task 11 blocks (~lines 1364–1402); reword plan line 1361 to: *"`tools: [read]` is the
  documented form; build 2.0.3's parser reads `groups:`, so both are set."* Do not claim on camera that a persona is
  read-only by declaration — the hook carries the claim.
